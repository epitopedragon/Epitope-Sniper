# NetMHCPan Epitope Sniper 🎯🔬

**NetMHCPan Epitope Sniper** is an interactive, web-based R Shiny application designed for high-throughput immunoinformatics screening, filtering, and visualization of T-cell epitope binding predictions generated by NetMHCpan outputs (`.xml`, `.xls`, `.txt`, `.out`).

---

## ✨ Features

- **Multi-Format Parsing:** Seamlessly processes NetMHCpan prediction files including XML, XLS, TXT, and raw text output tables.
- **Dynamic Binder Classification:**
  - **Strong Binders (SB):** Configurable rank threshold (default $\le 0.5\%$).
  - **Weak Binders (WB):** Configurable rank threshold (default $\le 2.0\%$).
  - **Non-Binders (NB):** Automatic classification for non-binding peptides.
- **Promiscuity Analysis:** Automatically detects and flags multi-allele promiscuous epitopes across target MHC molecules.
- **Interactive Filtering & Visualization:**
  - Filter by specific HLA / MHC alleles dynamically detected in the dataset.
  - Interactive table powered by `DT` with custom visual highlights and row status.
  - Summary metrics via real-time value boxes (Total, SB, WB, and Promiscuous counts).
- **Multi-Format Export Options:**
  - Export filtered candidate tables as **CSV**.
  - Export target peptide sequences as formatted **FASTA** files for downstream workflows.
